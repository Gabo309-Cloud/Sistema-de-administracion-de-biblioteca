
# Prototipo de sistema de Gestión de Biblioteca en Pyton

## Descripción
Este proyecto consiste en un sistema muy básico de gestión de biblioteca desarrollado en Python. Permite registrar y consultar libros, además de controlar sus préstamos y devoluciones.

## Funcionalidades
- Registrar nuevos libros.
- Mostrar los libros registrados.
- Buscar libros por título o autor.
- Registrar préstamos.
- Registrar devoluciones.

## Tecnologías utilizadas
- Python: lenguaje de programación utilizado para desarrollar el sistema.
- JSON: formato utilizado para almacenar los datos de los libros.

## Estructura del proyecto
- main.py: contiene el menú principal del sistema.
- biblioteca.py: contiene las funciones y la lógica del sistema.
- datos.json: almacena la información de los libros.

## Ejecución
Para ejecutar el programa, abrir una terminal en la carpeta del proyecto y utilizar:

```bash
python main.py
```
## Estado del proyecto
Este proyecto es en realidad un prototipo académico que implementa las funcionalidades básicas de gestión de una biblioteca.
